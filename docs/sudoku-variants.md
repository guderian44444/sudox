# 三種獨立數獨玩法／v61

> v62 的 COMBO、鍵盤與分層排行榜更新見 [combo-leaderboards-v62.md](combo-leaderboards-v62.md)。下文的共用層數與不送排行榜描述是 v61 行為。

開發與發布分支：`codex/sudoku-variant-modes`。v61 線上入口：https://guderian44444.github.io/sudox/ 。

## 玩家操作

開局視窗與難度側欄新增「經典／對角線／溫度計／Killer」四個互斥按鈕，預設經典。選好玩法後，仍可選輕鬆、動腦或高手難度，以及既有的阿霖不限失誤輔助。按下開始才顯示題目並計時；本局開始後鎖定玩法，下局或重新開始時可更換。

- 對角線：標示兩條對角線，每條也必須是 1–9 不重複。
- 溫度計：從圓球端向末端嚴格遞增，可以跳號；圖形在數字下方，不攔截點格。
- Killer：全盤以加總籠提供線索，沒有預填答案。虛線籠內不能重複數字，數字合計等於籠左上角標籤。點格後可查看該籠已填合計及剩餘總和。

三者皆沿用每行、每列、每個九宮格各含 1–9 的經典規則。對角線與 Killer 規則依 [Conceptis](https://www.conceptispuzzles.com/index.aspx?uri=puzzle/sudoku/rules)；溫度計採 [Logic Masters Deutschland 的嚴格遞增規則](https://logic-masters.de/Raetselportal/Raetsel/zeigen.php?chlang=en&id=000MQT)。

## 出題與流程

- 共用 MRV 求解器增加對角線、溫度計界限及籠的互異加總限制；唯一解檢查和候選寶物使用同一套約束。
- 對角線先建立符合雙對角線的完整盤；溫度計根據完整盤建立不重疊的遞增路徑，再逐格移除線索並檢查唯一解。
- Killer 從單格籠開始，每次只合併相鄰、數字不重複的籠，且合併後仍需通過唯一解檢查。籠涵蓋全盤、無重疊且連通。
- 出題搜尋達預算上限視為「未知」，不當作唯一解通過。難度由保留線索數、籠數／尺寸控制；尚無按解題技巧的專業難度評級。
- 新玩法由原生 module Worker 背景出題，有準備中、取消、錯誤重試與 15 秒逾時。取消或切換帳號後，舊 worker 的回覆不覆蓋目前盤面。
- 筆記、清除、一般提示、答案寶物與候選寶物可用。填格後會移除因變體限制已不可能的筆記。
- 原本格子局部更新保留；SVG 約束圖層固定，數字與筆記顯示在其上。

## 存檔與成就

- 每局保存 `variant`、`thermometers`、`cages`。重載包含途中局與待領卡片的完局資料；舊版沒有 `variant` 的局仍視為經典。
- 匯入／恢復時驗證模式名稱、溫度計路徑、籠的範圍與覆蓋／連通性、總和及解答符合規則。損壞的變體存檔不默默當作經典繼續。
- `floors.diagonal / thermo / killer` 分別保存各玩法的下一層，跨難度與阿霖輔助共用該玩法的層數；與原有經典輕鬆／動腦／高手／阿霖層數互不影響，雲端合併各自取較高層數。
- 通關、星星、零錯、零提示等通用成就照常累積；一般高手、經典四模式與阿霖系列不會被新玩法計數混入。未新增額外的成就金幣。
- 目前新玩法成績不送入既有四個經典排行榜，避免不同規則的分數互相比較。無 Supabase schema 變更；永久進度仍沿用既有雲端同步，中途盤面留在當前裝置。
- 請各裝置使用 v61 才能完整保留新的玩法欄位；舊版不支援這些盤面及層數。

## 驗證

- `npm.cmd run check:release` 納入 `scripts/test-variants.mjs` 及 worker 語法檢查。
- 90 題生成回歸：每模式、每難度各 10 題，檢查唯一解、解答一致、對角線／遞增／加總與籠不重複規則。
- 候選數字的正反例、畸形存檔拒絕、舊存檔相容、三種模式中途恢復、獨立層數與排行榜隔離、worker 遲到回覆及取消回歸。
- 隔離 Chromium 手機視窗：選模式與難度、候選寶物、正常輸入不重建棋盤、重載保留線條／籠、完局與領獎、再玩一局、回到經典、離線產生新題均通過，無頁面 JS 錯誤。
- 320／390／768／1280 px 版面檢查，手機截圖實際檢視；尚未使用 iPhone／iPad Safari 實機驗證。
