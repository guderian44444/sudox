# v59 BUG 修正與驗證

日期：2026-09-18。基準：v58 / b678afb。分支：`codex/fix-sudoku-stability`。
發佈來源：`codex/fix-sudoku-stability`，依使用者授權推送並由 GitHub Pages 發佈；`main` 保留原版。網址：https://guderian44444.github.io/sudox/ 。實際發佈結果以該分支的 Pages build 為準。沒有操作正式玩家／資料庫，未套用成就 V2 ZIP。

## 已修正

- A01 音效：集中管理 AudioContext；處理 suspended、interrupted、closed；恢復失敗會釋放並於下次操作重建。靜音保留、過期音效丟棄、音訊例外不阻斷填格。依據：[MDN 的 iOS Safari interrupted 說明](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/state#resuming_interrupted_play_states_in_ios_safari)。
- A02–03 互動：選格／填數／筆記只更新既有棋盤與狀態；存檔合併延後 120 ms，背景／離頁即保存。聲音即時播放，裝飾佇列限量，換局／離開清除計時器及特效；花園鰻同時最多一隻。
- A04 連對：已填格不再重複計分；清除再填、提示後重填及重新載入也不會刷連對獎勵。
- A05 同步：每次進度保存統一排同步；讀取遠端後才取本機快照；傳送途中有變更會補送。RPC 和排行榜連線設 12 秒逾時，涵蓋回應內容讀取；排行榜先落地待送資料再等待網路。同步／排行回傳會檢查玩家身分，避免切換玩家時套用舊帳號回應。
- A06 成就：合併已解鎖 ID、收藏與已結算局號，永久統計取高水位，避免被較少的紀錄覆蓋。可消費金幣不取最大值。
- A07 結算：通關獎勵及待領卡片一起寫入同一筆本機紀錄；runId 防止通關重發。領卡與領取狀態也一起保存。通關／失敗可以重載，尚未領完不可換局。提示寶物先記錄消耗，再結算最後一格。換玩家時立即保存新帳號與本機關卡。
- A08 計時：以 performance.now 的前景解題區間累積；小島、背景和功能視窗暫停，視窗開啟時隱藏盤面。凍結道具仍照原本規則扣除時間。
- A09 出題：共用最少候選格優先的位元遮罩求解器，保持既有題型、難度挖空與唯一解規則。
- A11 存檔：驗證解答行／列／宮合法、已完成盤面一致及寶物 ID。
- A12 保存／PWA：寫入失敗保留記憶體資料並顯示重試；重試包含尚未排入寫入的最新棋盤。只快取同源應用的成功回應；離線 HTML fallback 只用於導航；動畫參數共用同一資產快取。已升 v59 並列入全部新模組。
- A13 手機／鍵盤：遊戲中頂欄保留成就入口，成就與頭像視窗擋住棋盤快捷鍵。存檔頁明確說明盤面／計時／待領卡片只保存在本機。

## 已通過的驗證

`npm.cmd run check:release`：既有核心、小島、素材與版本檢查，以及 `scripts/test-stability.mjs` 全部通過。

新增回歸檢查涵蓋：同格重複／清除重填／提示重填、非法盤面與寶物、300 題唯一解、一次寫入結算、重載待領卡與防重領、儲存失敗重試、成就高水位、凍結及計時、模擬 iOS interrupted／closed／恢復失敗、同步期間變更與帳號切換、RPC 回應內容逾時、離線快取類型及資產去重。

實際 Chromium 手機尺寸 390×844、觸控模式、隔離測試玩家且停用雲端：填答不重建棋盤、重複輸入、成就視窗暫停及鍵盤阻擋、通關→重載→領卡→再次重載、下一局特效清空、小島暫停、離線重載、QuotaExceededError 後繼續填答及重試保存全部通過；無 JavaScript pageerror，頁面寬度 390 px 無水平溢出。

出題基準：同先前稽核的 seed=20260918，每難度 100 題，Node v24.17.0 本機；本次高手中位數約 0.25 ms、P95 約 0.45 ms、最慢約 0.99 ms。數字只量出題，不代表 iOS 點擊延遲。
