# v62 COMBO、鍵盤與分層排行榜

開發分支：`codex/combo-mode-leaderboards`。本機完成，尚未推送／部署；線上維持 v61。正式資料庫遷移已於 2026-09-19 由使用者在 SQL 編輯器執行成功；新 RPC 分類驗證已確認。

## COMBO

- 「答對 COMBO」：手動填對一個尚未解過的格子 +1。
- 「完成 COMBO」：首次完成一行、一列或一宮各 +1；同一步完成三個單位就 +3。中間填對但尚未完成新單位會保留 COMBO，沒有時間限制。
- 答錯（含護盾格擋與阿霖輔助）或使用填答案提示／寶物，兩項 COMBO 歸零。筆記與候選寶物不算答對，也不中斷。
- 擦除、重填及重新載入都不會重複計算同一格／同一單位。連擊與已完成單位保存在單局存檔。
- 數字增加時，原有顯示格放大並左右輕晃 420 ms，不重建棋盤或阻擋輸入；尊重系統「減少動態效果」。
- 原有首次連答八格／完成一行／一宮的回血或護盾保留，每局只領一次；COMBO 本身不新增金幣或無限回血。

## 桌面鍵盤

原本點格後焦點停在 button，鍵盤監聽器把所有 button 當作表單而略過。現在只略過輸入欄、選單、可編輯文字和開啟中的對話框。

- 主鍵盤 1–9、小鍵盤數字（Num Lock 開啟）：填入目前選取格。
- 方向鍵：移動選取格；Backspace／Delete／0：清除；N：切換筆記。
- 不攔截輸入法組字、Ctrl／Cmd／Alt 快捷鍵，也忽略長按重複事件。

## Killer 難度

Killer 沒有預填數字，但籠的總和與不重複規則就是線索，仍保留輕鬆／動腦／高手。

現有出題上限：每籠最多 3／4／5 格，目標 38／30／26 籠；每次合併都檢查唯一解，因此實際籠數可能較多。難度由籠大小及數量控制，尚非專業解題技巧評級。開局畫面已補充線索與難度差異說明。

## 排行榜與層數

- UI 先選經典／對角線／溫度計／Killer，再選難度。新模式另可切一般挑戰／阿霖輔助榜。
- 共 22 個分區：經典原有 `easy / medium / hard / alin` 四榜保留；三種新玩法各三難度 × 兩種輔助狀態，共 18 榜。原經典阿霖榜仍保留三難度共用的歷史規則，介面明確標示。
- 新榜鍵值例如 `killer_hard`、`killer_hard_alin`；提交、離線佇列去重、最高層數、查榜、留言、歷史 LOG 均按相同鍵隔離。
- v61 的 `floors.diagonal / thermo / killer` 是跨難度共用，無法可靠回推各難度成績，保留作為歷史資料。v62 的各難度與輔助旅程獨立從第 1 層開始；進行中的盤面保留，層數改用對應新旅程，舊金幣／成就不回收。v62 自己的局在重載／匯入時維持原層數。
- 各裝置請升級 v62，避免舊版存檔正規化時捨棄新欄位。
- 快速切換榜單時，較早查詢的遲到回覆不會覆蓋目前榜；留言回覆同樣鎖定送出時的分區。

## 資料庫套用與發布

既有 SUDOX 專案只需在 SQL 編輯器執行：

`supabase/leaderboard-variant-modes-migration.sql`

它在同一交易中擴充兩張榜單表的 difficulty 檢查限制，更新送分與留言 RPC 的有效鍵值，再重新載入 API schema。可重跑，不清除或改寫舊榜，不新增公開寫入權限。新專案的 `supabase/leaderboard.sql` 也已同步。

套用正式 SQL 後才部署 v62。若先更新網頁而資料庫尚未更新，新模式成績會留在本機待同步佇列，提供明確錯誤，不送到其他榜。
