## 玩家功能

- 6 個分類、15 個系列、94 個階段。每個系列包含 1／5／10／20／50／100；通關與星星系列另含 250／500。
- 同一系列累積達標、逐階解鎖，進度不歸零。各階有自己的名稱與收藏，每一階只領一次。
- 保留正式版原有 10 個成就的 ID 與金幣額度，合計 370 金幣；新增階段只給外觀。沿用 ZIP 規格中的 35 個 ID，再補足各系列階梯。
- 圖鑑提供分類、尚未滿階／已有收藏篩選、下一站進度、展開所有階段、未解鎖外觀預覽。
- 「我的收藏」可分別選擇一枚勳章、一個稱號、一款頭像框、一款棋盤角飾，亦可取消使用。選擇會存入本機／既有雲端存檔。
- 棋盤旁顯示稱號與勳章，手機亦可見。頭像框含系列標記；棋盤角飾使用對應系列的 SVG 圖形，不遮數字或攔截點擊。
- 完局一次列出本局全部新階段；重載可繼續看結果，不重複領金幣。多個解鎖合併成一次通知。

## 系列與判定

| 系列 | 累積條件 |
| --- | --- |
| 航海歷程 | 所有模式的通關局數 |
| 星光收藏 | 通關獲得的星星 |
| 完美解題 | 零失誤、零答案提示；筆記與其他寶物可用 |
| 精準航線 | 零失誤；提示和寶物可用 |
| 獨立解題 | 零答案提示；手動筆記、候選寶物可用 |
| 輕裝上島 | 未裝備／使用任何寶物，且未復活；一般提示、筆記可用 |
| 純粹挑戰 | 零失誤、零答案提示、零寶物、未復活；允許手動筆記 |
| 高手遠航 | 一般高手模式通關，不含阿霖 |
| 劍聖修行 | 一般高手模式的純粹挑戰 |
| 腦內棋盤 | 一般高手模式，沒有筆記操作、候選輔助、答案提示 |
| 乘風航行 | 取得原本的時間獎勵；休閒成就，允許暫停計時寶物 |
| 雷霆航路 | 一般高手模式的時間獎勵 |
| 逆風靠岸 | 一般模式曾剩 1 心、未復活並通關；曾歸零不計 |
| 彩虹同行 | 阿霖模式通關，含其三種難度 |
| 四海探索 | 輕鬆／動腦／高手／阿霖的完成數各達門檻 |

例如純粹挑戰的 5／10／20／50／100 局依序為「澄心五勝」「純粹十勝」「金線推理家」「孤高島主」「純粹百鍊」，各有不同收藏。

## 存檔與同步

- `achievementEvidence.version = 2`：舊版可證明的數字保存為 `base`，升級後每局以永久 `runId` 記入符合條件的 `proofs`。星星使用 `runId:1..3`。
- V2 裝置合併時，舊基準取較大值，局次證據作去重聯集。同一場重播不加次數，兩台離線各完成一局可累積兩次。
- 證據集合按目前最大門檻截斷：通關／星星各 500、其他各 100。排序後保留固定數量讓合併與順序無關。這是成就證據，不是無上限的歷史紀錄；日後增加更高階時須先調整上限，已截斷的額外歷史無法補回。
- 既有 `progress.completedGames`／`totalStars` 仍可在單機繼續累加；超出最高成就門檻後，跨裝置 lifetime 總數仍沿用舊版較大值策略。
- 舊的完美／速度／阿霖計數與既有成就保留；完美局可證明零錯、零提示。沒有明確歷史的純粹、無筆記、復活與一般難度次數從 V2 起算，不用舊層數猜測。
- 升級前開始的中途局可以繼續玩，但缺少 V2 全程紀錄時不發嚴格型成就。寫過再擦掉的筆記、候選寶物、金幣／卡片復活都會保留紀錄。
- 所有裝置更新到 V2 後，新增的局次才都有完整證據；舊版同時離線累積的未知歷史無法精確去重，不能當作完整帳本。
- 外觀只能套用已解鎖且確實提供該獎勵的 ID；取消、匯入、重載、雲端合併都經同一驗證。跨裝置採用較新存檔的外觀選擇。
- 移除原本成就清單只保留 50 個的限制，94 階可完整往返。升級／衍生資料修正不更新玩家操作時間戳，避免舊裝置覆蓋較新的雲端金幣與庫存。
- 不變更 Supabase schema 或排行榜頭像欄位。排行榜目前不展示成就外框；外觀用於玩家棋盤與圖鑑。
