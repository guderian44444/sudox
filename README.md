# 阿霖的數獨島

以 iPhone、iPad 與桌面瀏覽器為目標的銀髮友善可愛數獨遊戲。目前版本包含可玩的數獨核心、大字體介面、三段難度、提示與筆記、一般血量限制、無失敗次數限制的阿霖模式、經驗值升級、金幣、難度解鎖、無限時計時獎勵與離線快取。

## 冒險系統

- 輕鬆、動腦、高手分別有 5、4、3 顆初始愛心。
- 連續答對 8 格、完成一行或完成一宮，可回復愛心；滿血時轉為護盾。
- 輕鬆與阿霖模式提供不限次數免費提示。
- 血量歸零後可使用復活羽毛、金幣復活或重新挑戰。
- 八種寶物卡可以永久累積，每局開始前最多裝備兩種。
- 過關依錯誤與提示使用狀況取得一至三星，並從三張寶物卡中選一張帶走。
- 阿霖模式不限制失誤次數，仍保留完成獎勵與答錯統計。

## 啟動

需要 Node.js 18 以上版本，不需安裝任何套件。

```powershell
npm.cmd run dev
```

開啟 <http://localhost:4173>。

## 專案結構

```text
src/
  app.js          畫面組合、互動與遊戲流程
  styles.css      響應式視覺系統與 iOS 安全區
  game/sudoku.js  題庫、解題器、盤面規則
  game/adventure.js 血量、寶物卡、抽卡與星級規則
  state/store.js  玩家進度、獎勵與本機保存
scripts/
  dev-server.mjs  零依賴本機伺服器
```
