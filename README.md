# 數獨島 SUDOX

以 iPhone、iPad 與桌面瀏覽器為目標的可愛數獨遊戲主架構。目前版本已包含可玩的數獨核心、三段難度、提示與筆記、失誤限制、經驗值升級、金幣、連勝、難度解鎖與離線快取基礎。

## 啟動

需要 Node.js 18 以上版本，不需安裝任何套件。

```powershell
npm.cmd run dev
```

開啟 <http://localhost:4173>。

## 專案結構

```text
src/
  app.js          畫面組合、互動與遊戲流程
  styles.css      響應式視覺系統與 iOS 安全區
  game/sudoku.js  題庫、解題器、盤面規則
  state/store.js  玩家進度、獎勵與本機保存
scripts/
  dev-server.mjs  零依賴本機伺服器
```
